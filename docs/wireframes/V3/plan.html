How to review the Plan wireframes

Low-fidelity, grayscale, mobile-first, with a desktop layout under every phone screen (P8). Scope: Sprint 4, v0.5.0, part A: the training plan intake, the Plan page, the session and its actions. The plan-changed, missed-session, no-power-data, event, calendar and summary screens are in a separate file. Every screen has a stable ID (for example T5; the desktop version has a d after it) and numbered pins: write “T5 pin 2: …”. Type in the box under any screen, answer the open questions at the end of each section, then use Send your feedback. Notes stay in this browser. Numbers are illustrative, units are metric, times are Europe/Brussels. Inputs are always drawn empty with the label above and helper or error text below; a gray bar stands for typed text. Colour: only the training zones use colour (the real --zone-1 to --zone-7 tokens, light theme); a zone always shows its number and name as text. Everything else is gray.

What this file covers

  • T0: where Plan sits in the menu (one pair)
  • T1, T2: intake in four steps, then the summary and Build my plan
  • T3: the plan needs a baseline (empty state)
  • T4 to T6: overview, weekly view, today's session card
  • T7, T8: session detail, move, skip, mark done, Undo
  • T9: loading and error states

Not in this file

  • Plan changed notice, missed session, warning without power data, event and taper, calendar export, summaries to copy
  • Example plans and training load rules (Part A, item 4)

Working defaults drawn (Q-E2-9 to Q-E2-16)

  • Ranked purposes; weight loss with target and weekly cap; muscle building as bike strength plus notes; one event with taper; automatic re-planning with Undo. The PO corrects these while reviewing.

T0 · Menu: where Plan sits

Plan is its own item in the side menu (P7, P48), not a tab under Rides. One real choice: where in the list. The side menu has seven items now (P48 lists six). On desktop the menu is permanent; on the phone it opens from the top bar. Recommendation: A, Plan second. All desktop screens below use A.

Decisions about rules, scope and behaviour.

T1 · Plan intake and T2 · Summary

Intake is a stepper of four short steps (T1.1 to T1.4) and a summary (T2), shown as one page per step with its own heading. The answers are saved in the profile as they are given (backlog item 6), so a refresh or a detour to the profile does not lose them. These screens draw a plan that is about to be built (start Mon 2 Nov 2026); the plan screens later draw a plan in week 5. The plan is always 12 weeks (P59). Every input is drawn empty, with its label above and helper or error text below.

T7 · Session detail and T8 · Session actions

A session is warm-up, main set and cool-down as steps. Watts and heart rate come from the current zones (P40): the power zone and the heart rate zone each show their number and name as text next to a swatch in the zone colour (--zone-1 to --zone-7; heart rate zones reuse 1 to 5). Actions (mark done, move, skip, Undo) follow in T8. Numbers are from an FTP of 250 W and a maximum heart rate of 188 bpm, as in the Sprint 3 zones, and are illustrative.
