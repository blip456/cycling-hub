How to review the adapt wireframes

Low-fidelity, grayscale, mobile-first, with a desktop layout for every phone screen (P8). Scope: Sprint 4, v0.5.0, part A: what the plan adds to the profile and the weight screens, and everything that makes the plan adapt to real life (re-evaluation, missed sessions, matching, warnings), the event and taper, the calendar export and the summaries for an AI chat. The plan intake and the plan views are in the other V3 file. Every screen has a stable ID with the prefix R (for example R4; the desktop version has a d after it) and numbered pins: write “R4 pin 2: …”. Type in the box under any screen, answer the open questions at the end of each section, then use Send your feedback. Notes stay in this browser. Numbers are illustrative (FTP 250 W, weight about 75 kg), units are metric, times are Europe/Brussels. Inputs are always drawn empty with the label above and helper or error text below; a gray bar stands for typed text. Built on the V2 screens: Profile (H1, H2), Weight (W1, W2), the side menu and the status cards (P12, P31).
