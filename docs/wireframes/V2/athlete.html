How to review the athlete and weight wireframes

Low-fidelity, grayscale, mobile-first, with a desktop layout under every phone screen (P8). Scope: Sprint 3, v0.4.0, part A: the athlete profile and weight tracking. Baseline, test week and zones are in the other file. Every screen has a stable ID (for example W2; the desktop version has a d after it) and numbered pins: write “W2 pin 3: …”. Type in the box under any screen, answer the open questions at the end of each section, then use Send your feedback. Notes stay in this browser. Numbers are illustrative, units are metric, times are Europe/Brussels. Inputs are always drawn empty with the label above and helper or error text below; a gray bar stands for typed text.

H0 · Navigation change

Profile and Weight are new items in the side menu (P7). On desktop the menu is permanent; on the phone it opens from the top bar. One real choice: Weight as its own item (A) or under Profile (B). Recommendation: A. All desktop screens below use A.
