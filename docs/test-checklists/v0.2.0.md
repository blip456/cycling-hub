# Please try this: v0.2.0 (Sprint 1, Import & settings)

On your phone (installed app) and on your laptop, once the preview is live.

1. **Import the backfill.** Import → Choose file (phone) or drag the file onto the page (laptop) →
   your full `activities.json`. You should see "Import complete" with about 208 new rides and 97 not a
   ride (your 2014–2026 export).
2. **Import the same file again.** Everything should be "Unchanged"; nothing is duplicated.
3. **A broken file.** Remove a `distance` value from one activity in a copy of the file and import it:
   the rest is unchanged, the broken one is listed under "Skipped (errors)" with the reason.
4. **Not an export.** Import any other file (e.g. a photo renamed to `.json`): "Not imported", nothing
   changes, and it shows in Import history as "Not imported".
5. **Import history.** Every import is listed with its counts; tap one to see its summary.
6. **Settings.** Switch Theme between System, Light and Dark; it stays after closing the app. Check the
   version, What's new and What's next.
7. **What's new card.** After the next release: the card shows once (phone: at the bottom; laptop: in the
   side menu), and after you dismiss it, it doesn't come back on the other device either.

Questions: does the import summary tell you what you need? Is "Not a ride" clear for walks and hikes?

Good to know: the ride list itself arrives in Sprint 2 (v0.3.0). Power and heart rate stay empty until the
Chrome extension exports them (export format v2, Q1).
